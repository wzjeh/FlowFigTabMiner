You are extracting data from a flow chemistry heatmap figure. The figure shows the effect of residence time (tR) and temperature (T) on reaction yield (%).

## What to extract

1. **Axes**:
   - X-axis: title and tick values (usually tR in seconds, often log scale like 10^-2, 10^-1, 10^0)
   - Y-axis: title and tick values (usually Temperature in °C)
   - Identify if each axis is "log" or "linear" scale

2. **Data grid**: For every labeled data point (yield percentage printed on the heatmap), record:
   - The tR value (X-axis, in seconds — convert from scientific notation if needed, e.g. 10^-1 = 0.1)
   - The temperature value (Y-axis, in °C)
   - The yield value (the number printed at that grid point, in %)

3. **Caption**: The full text of the figure caption (usually below the figure, starting with "Figure N." or "Fig. N.")

4. **Context** (from caption, sub-figure labels, or molecule structures shown):
   - Sub-figure label if present (e.g., "a", "b", "c", "d")
   - Reaction description (e.g., "Trapping reaction of 2 with N-methoxy-N-methyl-3-phenylpropanamide")
   - Any compound IDs mentioned (e.g., "1a", "2", "3b")
   - Any molecule structure descriptions visible in the figure

## Important rules

- For log-scale X-axis: convert tick labels to actual seconds (10^-2 = 0.01, 10^-1.5 ≈ 0.032, 10^-1 = 0.1, 10^-0.5 ≈ 0.316, 10^0 = 1.0, 10^0.5 ≈ 3.16, 10^1 = 10.0, 10^1.0 = 10.0)
- Read every yield number visible on the heatmap grid — do not skip any
- If a data point has no visible yield number, omit it (do not guess)
- If the caption mentions multiple sub-figures (a, b, c...), only extract data for the sub-figure shown in THIS image
- If temperature tick labels use negative values (e.g., -78, -60), preserve the negative sign
- Return ONLY the JSON object, no other text
