# FlowFigTabMiner

Upload one flow-chemistry paper; figures (scatter plots, heatmaps) and tables
are read, the records are assembled with Gemini, and you download an
Excel/JSON file of reactions (reactants, product, conditions, yield).

Bring your own Gemini API key (used for that job only, never stored) or enter
the demo password. Code: https://github.com/wzjeh/FlowFigTabMiner
